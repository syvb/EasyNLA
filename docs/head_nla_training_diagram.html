Head NLA training pipeline

How one attention head's output becomes a training target for the head NLA on Qwen3-8B layer 24, and what changed in EasyNLA to train on it. The diagrams follow one target vector from the model's forward pass to an RL update. Code references are file:line at commit 7885d28, linked in the index at the end.

Most of the new code is on the data side. A new pipeline, nla/datagen/heads/, captures each head's output, turns it into a 4096-d vector, and writes training files whose AR text already names the head. The trainers are EasyNLA's own.

Injection is unchanged. The verbalizer (AV) gets the vector the standard EasyNLA way, a norm-matched add at the output of decoder layer 1. Only the vector is different: a head's write instead of the residual stream.

The AV never sees which head it is reading; the reconstructor (AR) always does. Every AR input starts with "Attention head L24Hh:", in SFT and in RL.

What changed in EasyNLA

Against main: 23 files, about 3,900 lines added. Most of it is the new data pipeline. The trainer changes are flags, and the final runs used only two of them, plus the matryoshka flags in the last run.

Unchanged EasyNLA pieces that the head NLA relies on:

  • the Karvonen injection hook;
  • the truncated AR (NLACriticModel, depth from the sidecar) and critic_predict;
  • SFT for both models;
  • the GRPO update with its frozen "reference" adapter;
  • AR co-training.
